# TaskMaster App

Tento repozitář obsahuje kompletní kód pro projekt TaskMaster (Frontend i Backend).

* **`/server`** - Obsahuje backendovou část (Express.js, routy a DAO z úkolu Backend #3).
* **`/src`** - Obsahuje frontendovou část (React, Vite).

*Poznámka: Repozitář byl přejmenován z původního `taskmaster-backend`, protože nyní obsahuje kompletní full-stack aplikaci.*
